# NeuroInfo · Presentación de la Unidad 4

Página de la actividad de entrega 2 de Contenerización de Aplicaciones de Software, Maestría en Ingeniería de Software del Politécnico Grancolombiano. La presentación de Sergio Miguel Peña Guerra se reproduce en la página y también se puede abrir directamente en YouTube.

- [Página de la entrega](https://video.neuroinfolab.com/)
- [Video en YouTube](https://youtu.be/XHcD7gDDCLE)

## Vista local

Desde la raíz del repositorio, inicia un servidor de archivos estáticos.

```powershell
python -m http.server 4322 --bind 127.0.0.1 --directory docs
```

Abre [la página local](http://127.0.0.1:4322/) en el navegador. El sitio se publica directamente desde `docs/` y la reproducción usa una conexión a YouTube.
